// identity

An equity can never masquerade as an option

One canonical format rules storage, lineage, mapping — and makes NSE-equity / NSE-F&O / BSE collisions impossible by construction.

EQUITY · NSE NSE_EQ|RELIANCE maps to RELIANCE.NSE inside Nautilus
SCRIP · BSE BSE_EQ|500325 numeric BSE codes kept distinct from NSE symbols
OPTION · NSE FO NSE_FO|BANKNIFTY-2026-09-24-CE-52000 expiry · strike · kind encoded in the id itself

// roadmap

Eight phases, built in order

Data first, execution last — exactly as Nautilus's own adapter guide prescribes.

Phase 1 · Repository & architecture DONE

Clean repo, canonical contracts, config system, testing infra, Docker, CI.

Phase 2 · NSE/BSE data acquisition DONE

MCP client over Streamable HTTP; raw store receives exact payloads before parsing.

Phase 3 · Normalization + quality DONE

Symbol/ISIN mapping, dedupe, corporate-action adjustment, gap detection, reports.

Phase 4 · Nautilus historical integration DONE

Validated parquet → catalog → BacktestEngine → fills/positions/account reports.

Phase 5 · Quant research engine DONE

Momentum, volatility, volume/delivery anomalies, regimes, event studies with significance tests.

Phase 6 · Upstox market-data adapter SCAFFOLD

Feed client + decoder interface ready; wire protobuf classes, replay vs stream parity test remains.

Phase 7 · Sandbox execution INTERFACE

ExecutionClient boundary mirrors Nautilus semantics; live construction physically refused.

Phase 8 · Production engineering NEXT

Observability, fault injection, rate-limit handling, deterministic-replay certification.

From zero to backtest in five commands

~/NSE-BSE-Event-Driven Quant Research Platform
$make setup # uv venv + install (nautilus_trader included)
$docker compose up -d mcp # nse-bse-mcp on :3000
$make ingest SYMBOL=RELIANCE FROM=2024-01-01 TO=2025-01-01
ingested 248 bars -> data/normalized/bars_1d/NSE/RELIANCE.parquet
$make validate SYMBOL=RELIANCE # quality gates (non-zero exit on errors)
$make sync SYMBOL=RELIANCE && make backtest SYMBOL=RELIANCE
